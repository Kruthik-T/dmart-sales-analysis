# D-Mart Sales Analysis Project

## Objective
Analyze D-Mart sales data and generate business insights using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Outlier Analysis
- Correlation Analysis
- Visualizations

## Key Insights
- Bengaluru generated the highest revenue.
- Electronics contributed the highest revenue due to laptop sales.
- Card payments were the most preferred payment method.
- Sales showed a declining trend after April.
- Premium products created statistical outliers but were valid business transactions.
